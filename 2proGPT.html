    2proGPT is an unblocked AI assistant designed to work in environments where other AI tools may be restricted. It offers multiple specialised modes, a coding canvas, voice input, and a full account system for saving your work.

    Built with plain HTML, CSS, and JavaScript — no external dependencies, no tracking, no ads.

    • ⚠️ AI responses are simulated in this demo — connect a real API key for live responses.
    • 💾 Account data is stored locally in your browser (localStorage). No data is sent to any server.
    • 🔒 Security Keys are 64-character strings you can use instead of a password to log in.
    • 🌐 OAuth buttons (Google, GitHub, Microsoft) are UI mockups — wire up real OAuth for production.
    • 🎨 Custom themes change the app colours immediately and are saved to your account.
    • How do I change my theme? — Go to Settings → Themes and pick Auto, Dark, Light, or Custom.
    • How do I save my chats? — Create an account; chats auto-save. Use Settings → Account → Save Data File for a manual backup.
    • What is a Security Key? — A 64-character string you can paste instead of a password. Add one in Settings → Account → Add Security Key.
    • How do I use voice input? — Click the microphone icon or the Voice button in the toolbar. Grant microphone permission if prompted.
    • Can I use 2proGPT without an account? — Yes! Accounts are optional and only used for saving data across sessions.
